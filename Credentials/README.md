# 자격 증명 학습 모음집

## GitHub [GH-900, GH-100]
GH-900, GH-100은 GitHub 관련 기능에 대한 정책 및 구성을 바탕으로 어느 정도의 지식을 학습하며 향후 더 나은 체계적인 보안 계층 구축과 관리 측면에서 비롯된 자격 증명입니다. 현재 개발되는 대부분의 코드들과 자동화는 GitHub에서 관리되는 상당한 리포지토리들에서 얼마나 효율적인 관리를 하는지 혹은 보안에서 취약점이 발생하는지를 이 자격 증명에서 보완할수 있다고 생각합니다.

> [!IMPORTANT]
> **2026년 07월에 GH-100[GitHub Admin]에 대한 자격 증명은 일부 기능이나 혹은 시험내 문제가 제거되거나 추가될 수 있다는 이슈가 발생하고 있습니다. 그렇기에 GH-100은 다가오는 7월 이후로 작성 진행합니다.**
