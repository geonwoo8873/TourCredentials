# GitHub Copilot

GitHub Copilot은 OpenAI Codex 시스템 기반으로 하여 사용자들이 코드를 사용하는 방법에 대한 광범위한 지식을 보유와 동시에 코드 생성에서 GPT-3보다 성능이 향상되어 개발되었다. 공용 소스 코드가 대량으로 포함된 데이터 세트에서 학습을 시작하였기 때문에 부분적인 많은 기능을 갖추고 있다. 다양한 IDE에 적용되어 개발에 대한 도구 모음의 확장 기능을 제공한다.

## GitHub Copilot Fectur<기능>

개발에 도움을 제공하는 코드 주석 형태로 자동 완성하여 개발자가 작업 흐름을 유지할 수 있도록 돕는 페어링 프로그래머이다. 하지만 자동 완료는 제공하는 기능 중의 일부에 속하며 단순한 편집기 이상의 기능을 제공하기 때문에 개발 수명 주기 전반에 걸쳐 쉽게 액세스할 수 있는 AI 보조 도구가 되어가고 있다.

### GitHub Copilot Chat

IDE 내에서 직접 대화형 채팅 환경이 포함되어 있으며 다음과 같은 수행을 할 수 있다.

* 코드에 대한 질문
* 논리 또는 오류에 대한 설명
* 테스트 또는 설명서 생성
* 새 기능을 구현하는 방법 제안

## GitHub Copilot Pull Request Summary<요약>

끌어오기 요청을 오픈하면 변경 내용에 대한 요약 설명을 자동으로 생성할 수 있기 때문에 검토자가 의도를 이해하고, 텍스트를 작성하는 작업에 대한 시간과 과정을 줄이며 공동 작업의 명확성을 향상시킬 수 있다.

### GitHub Copilot Pull Request Review Support<지원>

검토 과정에서 잠재적인 문제를 제안하고, 변경 내용에 대한 부분을 설명하며 에러 사례를 지적하면서, 검토자에게 개선 사항을 제안해 코드 검토 워크플로를 지원할 수 있다. 이러한 기대 효과에 검토 주기의 속도를 높이고 수동 오버헤드를 감소 시킬 수 있다.

## GitHub Copilot CLI<Command Line Interface>

편집기와 끌어오기 요청 다음으로 개발자는 터미널에서 많은 시간을 소모하며 숙련된 개발자라 할지라도 수많은 명령어의 정확한 구문을 기억하기 위해선 여러 페이지를 확인해야하기 때문에 이를 위해 GitHub Copilot CLI를 사용하면 다음과 같이 수행할 수 있다.

* 명령 제안 및 코드 조각 요청
* 셀 스크립트 생성
* 출력 또는 오류를 이해
* CLI에서 프로젝트 생성 및 개선

## GitHub Copilot Space

스페이스 공간에서 프로젝트에 대한 AI와 공동 작업할 수 있는 전용 영역을 제공한다. 이에 대한 다음과 같이 기능을 수행 할 수 있다.

* 프로젝트 구조 확인
* 고차원적 계획 제안
* 요구 사항 구체화
* 디자인 반복 수정

이와 같이 Copilot이 리포지토리 및 워크플로에 대한 지식을 보유하는 컨텍스트가 원할한 환경을 제공한다.

## Copilot Cloud Agent

클라우드만의 에이전트가 제공하는 지원 역할은 다단계 작업을 수행한다.

* 여러 연관된 파일 생성
* 기능 집합 구현
* 특정 사양의 스캐폴딩<`자동 구성`> 빌드

사용자의 지시에 따라 이러한 작업을 실행하여 복잡한 워크플로를 빠르게 완료하고 흐름을 유지하는 데 기여한다.

## Copilot Plans

GitHub에서는 개발된 Copilot에 대한 사용 범위를 각 플랜에 따라 할당량을 제공하고 향후 각 플랜에 따른 비용 할인 범위와 기능을 제공한다.

### Free Plan

모든 GitHub에 생성된 계정의 소유자 및 사용자들은 무료로 제공되는 GitHub Copilot을 사용할 수 있다. IDE를 실행시키거나 CLI 혹은 GitHub에서 이용할 수 있으며 자격증명<로그인>을 안료하면 무료 계층에서 제공되는 할당량에 허용하는 한 사용이 가능하다.

무료 플랜에는 다음과 같이 할당량과 기능을 제공한다.

* 할당량
    * 매월 2,000개의 코드 완성
    * 매월 50개의 채팅 요청
    * GPT-4o 혹은 Claude 3.5 Sonet 모델 제공

### Pro Plan

Pro Plan은 Free Plan에서 더 많은 할당량과 기능을 제공하며 월 10$에 준하는 비용을 지불해야 한다.

Pro Plan에는 다음과 같이 기능을 제공한다.

* 할당량 & 기능
  * 무제한 코드 완성 및 채팅 요청
  * 최신 AI 모델에 대한 우선 액세스
  * 고급 코드 제안 및 설명
  * 지원 중인 IDE의 통합
  * 자동화된 테스트 생성 및 코드 설명 기능

### Pro Plus Plan

프리미엄 모델 사용량 및 수요가 많은 리소스의 우선 순위 성능에 대한 추가 액세스 권한이 있는 모든 기능이 포함되어 있으며, 평균 사용량이 많은 개인에게 적합하다.

Pro Plus Plan에는 다음과 같이 기능을 제공한다.

* 기능
  * 모든 Pro 기능 제공
  * 추가 프리미엄 요청 용량
  * 우선순위 인프라 접근

### Business Plan

리포지토리나 조직의 관리자가 Copilot 액세스를 관리하고 추가 보안 및 규정 준수 기능을 활용을 추구하는 조직을 위한 플랜이다.

Business Plan에는 다음과 같이 기능을 제공한다.

* 기능
  * 조직 구성원을 위한 모든 Pro 및 Pro+ 기능
  * 중앙 집중식 관리 및 정책 제어
  * 보안 취약성 필터링
  * 코드 참조 및 공용 코드 필터링
  * IP 배상 및 엔터프라이즈급 보안, 안전 및 개인 정보 보호
  * IDE 및 모바일에서 채팅
  * 공용 코드에 대한 필터


### Enterprise Plan

고급 기능, 심층 통합 및 향상된 개인 설정이 필요한 대규모 조직 및 기업을 위해 설계된 제품이다.

Enterprise Plan에는 다음과 같이 기능을 제공한다.

* 기능
  * 모든 비즈니스 기능
  * 내부 혹은 프라이빗 코드를 기반으로 하는 개인 설정된 코드 제안
  * GitHub Enterprise Cloud와 통합
  * 코드베이스 전체에서 AI 기반 검색 및 설명서 생성
  * AI 기반 태그 및 요약을 사용하여 향상된 끌어오기 요청 지원
  * Copilot 모델의 조직 전체 사용자 지정 및 미세 조정
  * 채팅 및 코드베이스 탐색을 위해 GitHub와 긴밀하게 통합
