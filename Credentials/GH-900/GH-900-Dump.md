# Git

Q. 중앙 집중식 버전 제어 시스템과 분산 버전 제어 시스템의 주요 차이점은 무엇인가요?  
A. 중앙 집중식 시스템은 코드 스토리지에 중앙 집중식 서버를 사용하지만 분산 시스템에는 서버가 필요하지 않습니다.

Q. Git 용어에서 "원격"이란 무엇인가요?  
A. 동일한 프로젝트를 추적하지만 다른 위치에 있는 리포지토리입니다.

Q. Git은 여러 개발자 간의 협업에 어떻게 도움이 됩니까?  
A. Git을 사용하면 개발자가 프로젝트의 자체 복사본에서 작업하고 변경 내용을 원활하게 병합할 수 있습니다.

Q. Git과 GitHub 간의 차이점은 무엇인가요?  
A. Git은 로컬로 실행되는 DVCS(분산 버전 제어 시스템)입니다. GitHub는 공유 원격을 제공하는 인터페이스 계층입니다.

Q. Git을 사용하는 방법에 관한 정보를 제공하는 Git 명령은 무엇인가요?  
A. git 도움말

Q. Git의 "분기"란 무엇인가요?  
A. 특정 기능 또는 작업에 대한 커밋의 별도 타임라인입니다.

# GitHub

Q. GitHub의 문제, 토론 및 끌어오기 요청의 차이점은 무엇인가요?  
A. 문제는 변경 사항을 제안하고, 일반적인 프로젝트 토픽에 대한 토론이며, 끌어오기 요청은 코드 검토 및 병합을 위한 것입니다.

Q. GitHub Enterprise 제품으로 업그레이드하는 가장 좋은 이유는 무엇인가요?  
A. 여러 조직의 사용자 및 리포지토리를 중앙에서 관리하려고 하기 때문입니다.

Q. GitHub Mobile에서 실행할 수 있는 함수는 무엇인가요?  
A. github.com에서 알림을 관리, 분류, 지우기

Q. GitHub 리포지토리에서 새 문제를 만들려면 어떻게 해야 할까요?  
A. "새 문제" 버튼을 클릭하고 세부 정보를 입력합니다.

Q. GitHub에서 사용자의 공개 활동을 최신 상태로 유지하고 알림을 받는 방법은 무엇인가요?  
A. 사용자를 팔로우합니다.

# Repository

Q. 리포지토리에 변경 내용을 적극적으로 푸시해야 하는 참가자에게 적합한 권한은 무엇인가요?  
A. 작성 권한(Write)

Q. PR(끌어오기 요청)을 GitHub 문제에 연결하려면 어떻게 해야 할까요?  
A. 문제 설명에서 PR 번호를 언급합니다.

Q. 특정 GitHub 사용자에게 문제를 할당하려면 어떻게 해야 합니까?  
A. 문제의 "담당자" 섹션을 사용합니다.

Q. GitHub 리포지토리 내에서 특정 문제를 검색하려면 어떻게 해야 합니까?  
A. 전역 GitHub 검색 창을 사용합니다.

Q. GitHub 마일스톤을 만들려면 어떻게 해야 할까요?  
A. "문제" 탭에서 "마일스톤"을 선택 후 "새 마일스톤" 클릭

Q. GitHub 끌어오기 요청에서 "기본" 및 "비교" 분기를 비교하는 목적은 무엇인가요?  
A. 두 분기의 코드 간 차이점을 보여줍니다.

Q. GitHub 끌어오기 요청에서 다양한 탭의 용도는 무엇인가요?  
A. 끌어오기 요청과 관련된 컨텍스트, 변경 내용 및 토론을 제공합니다.

Q. GitHub 프로젝트에서 만들 수 있는 보기 유형은 무엇인가요?  
A. 테이블, 보드, 로드맵

Q. GitHub Gists는 주로 어떤 용도로 사용됩니까?  
A. 작은 코드 조각 또는 텍스트 노트를 공유하고 공동 작업합니다.

Q. GitHub Wiki 페이지는 어떻게 편집 및 유지 관리합니까?  
A. 적절한 권한이 있는 사용자가 GitHub 웹 인터페이스를 통해 수정할 수 있습니다.

Q. 오픈 소스 프로그램과 InnerSource 프로그램 간의 관계를 가장 잘 설명하는 선택 항목은 무엇입니까?  
A. InnerSource 프로그램은 기본적으로 오픈 소스 프로그램과 동일합니다. 단, 해당 액세스는 조직 내의 사용자로 제한됩니다.

Q. 팀은 저품질 버그 보고서를 받고 있습니다. 가장 좋은 해결 방법은 무엇인가요?  
A. ISSUE_TEMPLATE.md 파일을 추가하여 재현 단계, 시스템 속성, 로그를 포함하도록 합니다.

Q. InnerSource 프로그램이 개선되고 있음을 나타내는 메트릭은 무엇인가요?  
A. 소프트웨어의 버그를 해결하는 끌어오기 요청이 크게 증가합니다.

Q. 별표(*) 및 밑줄(_)과 같은 특정 예약 문자를 Markdown에 표시하려면 어떻게 하나요?  
A. \\* 또는 \\_처럼 역 슬래시로 이스케이프 처리합니다.

Q. GitHub Marketplace란 무엇인가요?  
A. GitHub에 대한 추가 기능을 검색하고 설치하는 장소입니다.

Q. Codespace의 수명 주기는 어떻게 정의되나요?  
A. 생성 시 시작되고 삭제 시 종료됩니다.

Q. Codespace를 사용하는 동안 인터넷 연결이 끊어지면 어떻게 되나요?

Q. 가장 안전한 버전의 프로젝트 종속성을 통합하는 방법은 무엇인가요?
