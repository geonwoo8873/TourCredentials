# 2. GitHub Foundation [`GH-900`]

`GitHub Foundation`은 GitHub에서 제공하는 개인 사용자와 조직 및 오픈 소스에 대한 공동 작업을 개념과 이해의 유효성을 다룬다.

# 3. GitHub Administration [`GH-100`]

`GitHub Administration`은 [GitHub Foundation](#2-github-foundation)에서 다루는 내용에서 딥 다이브한 엔터프라이즈급의 작업 규칙 및 개념과 이해의 유효성을 다룬다. 다순히 작업에서 발생하는 보안 리스크와 효율성을 중심으로 제공되는 `GitHub Actions`에 대한 `Self-Hosting`의 중요성을 알려주고, GHEC와 GHES에 대한 개발 및 배포 모두 지원하며 보안 및 운영 팀과 협력으로 효과적으로 사용할 수 있도록 한다.
