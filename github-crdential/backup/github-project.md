# GitHub Project Classic

## 프로젝트 개선 사항의 포괄적 목록

### 테이블 및 보드

* 테이블 또는 보드 뷰에서 작업 계획 및 추적
* 사용자 지정 필드 기준으로 테이블 내 작업 순위 지정과 정렬 및 그룹화
* 자세한 설명 및 메타데이터 사용한 초안 문제 생성
* 토큰화된 핉터링 및 저장된 뷰를 사용하여 큐브 뷰 구체화
* 프로젝트 보드에서 카드 및 그룹화 사용자 지정
* 실시간 프로젝트 업데이트 및 사용자 현재 상태 표시

### 데이터

* 텍스트, 숫자, 날짜, 반복 및 단일 선택 형식의 사용자 지정 필드 정의
* 스프린트, 주기 또는 분기별 로드맵을 표시하도록 유동적인 날짜 범위 및 중단으로 반복 구성
* 테이블 및 보드 뷰 모두에서 연결된 끌어오기 요청 및 검토자 보기

### 인사이트


* 사용자 지정 막대형, 세로 막대형, 꺾은선형 및 누적 영역형 차트 생성 및 구성
* 합계, 개수, 평균, 최소 및 최대와 같은 집계 함수를 사용하여 적절한 인사이트 제공
* 차트를 유지하고 URL과 공유하여 모든 사용자가 인지할 수 있도록 공유 가능

### 자동화

* GraphQL ProjectsV2 API 연동
* GitHub App 프로젝트 범위
* 프로젝트 항목 메타데이터 업데이트에 대한 웹후크 이벤트
* 프로젝트에 문제 추가를 자동화하는 GitHub 작업

## 프로젝트 생성

GitHub Project는 팀에게 테이블, 보드 및 타임라인과 같은 유연한 보기를 제공하여 작업을 구성하고 더 큰 그림을 볼 수 있는 편의성과 효율성을 제공하며 계획 및 추적 도구이다.

팀의 기능 백로그를 한 곳에서 관리하려는 경우에 프로젝트 기능을 사용하면 단일 보기에서 모든 항목을 쉽게 구성, 우선 순위 지정 및 추적이 가능하다.
