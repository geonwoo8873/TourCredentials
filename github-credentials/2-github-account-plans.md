# 1. 깃허브 사용자 계정 타입 (GitHub User Account Types)

## 1.1 개인 (Personal)

* 모든 사용자는 개인 계정으로 로그인하여 **GitHub.com** 통해 자신의 **고유 ID**와 **이름** 및 **프로필 정보**를 생성하여 보유할 수 있다.
* 리포지토리내 보존되어 있는 패키지 및 프로젝트와 같은 데이터들은 개인 자산들로 소유와 권한을 관리하며 간단한 방법을 통해 유지보수와 용이함으로 관리가 가능하다.
* **Pull Request**와 같이 GitHub에서 수행하는 작업들은 개인 계정으로 귀속되며 **퍼블릭**과 **프라이빗** 두 가지의 형태의 리포지토리를 생성할 수 있지만 프라이빗은 일부 기능 제한을 받는다.

## 1.2 조직 (Organization)

* 사용자가 한 번에 여러 프로젝트에서 협업할 수 있는 공유 계정으로 조직 계정의 권한은 계층화된 접근 방식으로 수행 한다. **단 조직 계정은 직접적인 로그인이 불가하다.**
* 각 사용자는 개인 계정으로 로그인하여, 조직 리소스에 대해 수행하는 모든 작업은 계정에 귀속되며, 개인 계정은 여러 조직의 협력자가 될 수 있다.
* 조직 내의 다양한 역할을 지정 받거나 부여할 수 있으며, 역할에 따라 조직 및 해당 데이터에 대한 각 다른 수준의 액세스 권한이 부여된다.
* 조직 내 모든 멤버는 리포지토리 및 프로젝트에서 공독 작업이 가능하나 조직 소유자 및 보안 관리자만 조직의 설정을 관리하고 보안 및 관리 기능을 사용하여 조직의 데이터에 대한 엑세스를 제어할 수 있다.

## 1.3 기업 (Enterprise)

* 관리자가 여러 조직에 대해 정책 및 청구를 **중앙 관리 방식으로 관리**하며 조직 간에 내부 소싱을 사용하도록 설정할 수 있고, 조직 또는 사용자 계정과 같은 핸들이 있어야 한다.
* 조직은 기업 구성원이 여러 프로젝트에서 한 번에 협업할 수 잇는 공유 계정이지만 설정에서 소유자는 기존 조직을 초대하거나 계정 간 조직을 이전 혹은 생성할 수 있다.
* 엔터프라이즈 계정에 소요한 모든 조직에 대한 정책을 관리하고 적용할 수 있으며 각 엔터프라이즈 정책은 조직 수준에서 사용할 수 있는 옵션을 제어한다.
 
# 2. GitHub Plans

> [!CAUTION]
> **2026년 06월 01일 부터 모든 GitHub Copilot 플랜들의 프리미엄 요청 비용 집계 방식을 변경하여 모든 행위에 대한 크레딧 책정으로 변경된다.**

GitHub는 코드 저장 및 협업을 위한 무료 및 여러 유료 요금제를 제공한다. 일부 요금제는 개인 계정에게만 제공되지만 그외는 조직 및 기업 계정에만 제공된다. 각 플랜의 비용과 기능은 GitHub Pricing에서 확인할 수 있으며 향후 지원되는 기능과 제품에 대한 정보는 공개 로드맵에서 확인할 수 있다.

## 2.1 GitHub Free

GitHub에서 생성시 적용되는 기본적인 요금제로 리포지토리 생성에 제한은 없지만 프라이빗 리포지토리의 협력자 제한이나 타 플랜보다 할당량 및 제공되는 기능은 제한된다.

* GitHub 커뮤니티 지원
* Dependabot 알림
* 2단계 인증 적용
* 500MB GitHub 패키지 스토리지1
* 매월 120분의 GitHub Codespace 코어와 15GB의 GitHub Codespaces 스토리지
* 매월 2,000분과 퍼블릭 리포지토리에 대한 배포 보호 규칙을 적용한 GitHub Actions

> [!IMPORTANT]
> **Organizations에서도 Free 플랜이 제공되며 무제한 공개 저장소나 제한된 기능의 개인 저장소에서 협업할 수 있다.**
> **단, GitHub 커뮤니티 지원과 팀 접근 제어 및 월 2,000분의 GitHub Actions를 제공한다.**

## 2.2 GitHub Pro

GitHub Free에서 고급 인사이트 기능과 프라이빗 협력자를 협업가능으로 구성된 제품이다.

* 전자 메일을 통한 GitHub 지원
* 매월 3,000분의 GitHub Actions
* 2GB GitHub Package 스토리지
* 매월 180분의 GitHub Codespaces 코어와 20GB GitHub Codespaces 스토리지
* 프라이빗 리포지토리의 고급 도구 및 인사이트
  * 끌어오기 요청 검토자 필요 및 여러 끌어오기 요청 검토자
  * 보호된 분기
  * 코드 소유자
  * 자동 링크된 참조
  * GitHub Page
  * 위키
  * 리포지토리 인사이트 그래프 [`펄스, 기여자, 트래픽, 커밋, 코드 빈도, 네트워크, 포크`]

## 2.3 GitHub Team

조직용 GitHub Free에서 사용할 수 있는 기능 외에 향상된 협업, 보안 및 워크플로 관리 기능이 필요한 조직을 위해 설계되어 관대한 권한이 포함되지만 팀이 효율적이고 안전하게 작업할 수 있도록 지원하는 고급 기능에 있다.

* 전자 메인 GitHub 지원

* 매월 3,000분의 GitHub Actions
* 2GB GitHub Package 스토리지
* 프라이빗 리포지토리의 고급 도구 및 인사이트
  * 끌어오기 요청 검토자 필요
  * 여러 끌어오기 요청 과 팀 끌어오기의 검토자 와 초안 끌어오기 요청
  * 보호된 분기
  * 코드 소유자
  * 알림 예약
  * 설명서 및 웹 콘텐츠에 대한 GitHub 페이지 및 Wiki 제공
* 리포지토리 인사이트 그래프 [`펄스, 기여자, 트래픽, 커밋, 코드 빈도, 네트워크, 포크`]

## 2.4 GitHub Enterprise

대규모 조직에 대해 향상된 지원, 보안, 규정 준수 기능 및 고급 배포 제어를 제공한다. Enterprise에 등록할 때 전용 계정을 생성하고 그에 따른 소유자는 여러 조직을 관리하고, 관리자 액세스를 제어하며 전체 기업에서 일관된 보안 정책을 적용할 수 있다.

* 전용 Enterprise 지원
* 보안 및 규정 준수과 배포 기능
* 외부 ID 공급자를 통한 중앙 집중식 사용자 인증 및 관리
* 프라이빗 또는 내부 리포지토리에 대한 배포 보호 규칙
* GitHub Enterprise Server와 Cloud 간에 선택한 데이터를 안전하게 공유할 수 있는 GitHub Connect를 통해 통합 기여, 중앙 집중식 사용자 ID 및 환경 전반의 가시성 향상
* 향상된 코드 및 중속성 보호를 위해 GitHub Advanced Security 구해 옵션

> [!IMPORTANT]
> **GitHub Page는 계정 유형에 따라 게시가능한 형태가 다르다. 기본적으로 공개 게시로 적용되지만 비공개 게시로 전환해야 한다면 조직 또는 기업 계정이 필요하다. 또한 GitHub Enterprise Cloud를 사용해야 한다.**  
> **GitHub Codespaces를 활성화 여부를 체크하는 옵션은 조직 소유자 한정에만 설정할 수 있으며, 사용자와 협력자의 사용률 비용을 지불해야 한다. 이는 GitHub에서 제공하는 Codespace 약관을 참고하면 된다.**
